# Isa Clicker

A Cookie Clicker–style idle game starring Isa. Click Isa to earn Isa's, buy upgrades, level up, open chests and banner cases, adopt pets, and survive the boss fight every 10 levels.

## Play

Open `index.html` in a browser, or play the GitHub Pages link for this repo.

Progress saves in your browser automatically (each browser and device has its own save).

## Publish on GitHub Pages

1. Create a new repository on GitHub (for example `isa-clicker`).
2. On the repo page, choose **Add file → Upload files**, drag in every file from this folder, then click **Commit changes**.
3. Go to **Settings → Pages**. Under **Build and deployment**, set **Source** to **Deploy from a branch**, pick the **main** branch and the **/ (root)** folder, then click **Save**.
4. Wait a minute or two, then refresh that page. Your link appears at the top, like `https://YOUR-USERNAME.github.io/isa-clicker/`.

To update the game later, upload the new `index.html` (or other files) the same way and the site updates within a minute or two.

## Files

- `index.html`: the whole game (code, styles, music and sounds)
- `isa1.jpg` to `isa4.jpg`: Isa's photos
- `edwin.jpg`, `angel.jpg`, `zac.jpg`: battle fighters
- `f_*.jpg`: face crops used for pets and banners
